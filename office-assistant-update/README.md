# Office 길잡이 랜덤 동작 수정본

## 적용 내용

사용자가 제공한 투명 PNG의 일곱 가지 정지 포즈를 그대로 표시하며, 포즈 전환과 짧은 CSS 움직임으로 여섯 동작을 재생합니다. 원본 Office 프로그램의 전체 프레임 애니메이션을 복원한 것은 아닙니다.

- 주변 둘러보기, 고개 갸웃하기, 책 읽기, 전화하기, 낮잠 자기, 책상에서 쉬기
- 참고 영상 8:22 부근처럼 낮잠 뒤 몸을 세우고 고개를 든 채 잠깐 멈춘 다음 앉는 단계식 동작
- 처음 나타날 때 작은 집에서 두 번 가볍게 뛰어나와 고개를 들고 자리를 잡으며, 숨길 때 같은 리듬으로 다시 집으로 돌아가는 출입 동작
- 첫 동작은 약 0.7~1.5초 뒤 시작하며, 동작 사이에 약 1.5~3초 쉬기
- 한 묶음 안에서 모든 동작을 한 번씩 재생하고, 같은 동작의 연속 재생 방지
- 말풍선을 열거나 브라우저 탭이 숨겨지면 중지
- 운영체제의 동작 줄이기 설정을 따름
- 옵션(O)의 자동 재생 체크박스와 '다른 동작 보기' 버튼
- 기존 키워드 검색, Enter, Esc, 길잡이 숨기기 및 재표시 유지

## 원본 프로젝트 반영

원본 위치: `D:\my_project\portfolio`

현재 작업의 권한 설정이 원본 폴더 쓰기를 거부하여 원본에는 아직 반영하지 않았습니다. 이 폴더의 `src`와 `public` 파일을 원본 프로젝트의 동일 경로에 병합하면 됩니다. 원본의 `src/App.jsx`만 교체되고 네 파일이 추가됩니다. 기존 `App.jsx`를 먼저 백업하세요. 수정본은 이 작업에서 확인한 원본 버전을 기준으로 하므로 그 이후에 원본을 편집했다면 변경 내용을 병합해야 합니다.

변경 파일:

1. `src/App.jsx` — 캐릭터 연결 및 애니메이션 옵션
2. `src/components/OfficeMascot.jsx` — 타이머, 일시 정지 및 정리
3. `src/components/mascotActions.js` — 포즈 영역, 동작 순서, 랜덤 선택
4. `src/components/OfficeMascot.css` — 포즈 표시와 동작, 말풍선 스타일
5. `public/office-actions-reference.png` — 사용자가 제공한 원본 PNG 그대로

추가 패키지는 필요하지 않습니다. 반영 후 프로젝트 폴더에서 `npm run dev`를 실행하세요.

수정본에서 프로덕션 빌드 및 코드 검사 통과. 브라우저에서 랜덤/수동 동작, 옵션, Enter 검색, Esc 닫기, 숨기기·재표시, 경력 섹션 스크롤을 확인했습니다. 검사 중 브라우저 오류는 없었습니다.
